# Flag Browser

Flag Browser is a Windows desktop utility for managing local FastFlag-style configuration values with profiles, search, import/export, and update support.

## Features

- Browse and edit flag values
- Save reusable profiles
- Import and export flag sets
- Apply selected values from the desktop UI
- Optional update manifest support
- Local settings stored per user

## Requirements

- Windows 10 or newer
- .NET 8 runtime or SDK, depending on how the app is distributed
